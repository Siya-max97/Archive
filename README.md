
# Archive

A curated digital archive of architecture, exploring remarkable buildings, architectural movements, places, and ideas through visual storytelling.

## Overview

Archive is a web-based architecture platform for discovering remarkable buildings, architects, places, and architectural movements through curated collections and visual galleries.

## Features

- Browse curated architectural collections.
- Discover building profiles and architectural movements.
- Explore buildings by location, architect, and historical period.
- View visual galleries and architectural references.
- Navigate dedicated collection and building pages.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
